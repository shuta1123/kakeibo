# 家計簿アプリ
収入・支出の管理から貯金目標の達成まで、シンプルで賢い家計簿アプリです。

## 特徴

定期支出の自動登録 — 家賃・サブスクなどを登録しておくと毎月自動で追加
異常検知 — 先月比で支出が増えたカテゴリを自動で警告
来月の予測 — 過去のデータをもとに来月の支出を予測
貯金目標管理 — 目標金額と期限を設定し、進捗を可視化
カテゴリ予算 — カテゴリごとに上限を設定してオーバーを防ぐ
週次レポート — 毎週の支出サマリーを自動生成


## 技術スタック
役割技術フロントエンドTypeScript / ReactバックエンドPython / FastAPIデータベースSQLiteグラフRecharts

## 機能一覧
### 基本機能

収入・支出の入力（日付・カテゴリ・金額・メモ）
月別一覧表示・フィルター
合計・残高の表示
カテゴリ別グラフ（円グラフ・棒グラフ）

### 定期支出の自動登録

名前・カテゴリ・金額・引き落とし日（1〜31日）を登録
毎日深夜0時に自動チェックし、該当日にDBへ追加
29〜31日指定時はその月の末日に自動調整
is_active フラグで一時停止が可能

### 異常検知

カテゴリごとに先月比を比較
20%以上増加した場合に警告表示

### 来月の予測

過去3ヶ月の移動平均をもとに来月の支出を予測
グラフ上に予測ラインを表示

### 貯金目標

目標金額と達成期限を設定
月あたりの必要貯金額を自動計算
進捗バーで達成率を表示

### カテゴリ予算

カテゴリごとに月の上限金額を設定
使用率をゲージで表示（超過時は赤色表示）

### 週次レポート

毎週日曜日に自動集計
カテゴリ別サマリー・異常検知結果を表示
